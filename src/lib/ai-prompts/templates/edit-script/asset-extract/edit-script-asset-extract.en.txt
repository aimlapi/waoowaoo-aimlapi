Rules:
- kind must be character, location, or prop.
- Do not extract audio, storyboard images, videos, or final film in phase one.
- name must be short, stable, and reusable.
- description must objectively state why this asset is needed and include visible identity, space, era, material, or key visual evidence from the edit table.
- shotNumbers must come from the edit table shot numbers.
- Do not extract unnamed featureless extras, pure background crowds, mentioned-only entities, abstract concepts, or narration objects as characters.
- Merge aliases of the same character into one stable name.
- Do not extract passing locations, mentioned-only places, abstract spaces, figurative spaces, prop close-ups, or pure moods as locations.
- Merge aliases of the same physical space into one stable location name.
- Extract a prop only when it satisfies at least one condition:
  1. World-rule prop, such as a detection device, identity-judgment device, or punishment mechanism.
  2. Character identity or value-turn prop, such as an emblem, token, or object that is repeatedly worn, touched, discarded, or destroyed.
  3. Action-conflict core prop, such as a tool repeatedly used for pursuit, binding, attack, defense, or escape.
  4. Climax target or set piece, such as an object that is finally shattered, seized, sacrificed, destroyed, or activated.
  5. Recurring symbolic prop that drives a system metaphor or emotional turn.
- Do not extract ordinary tables, chairs, walls, clothing, shoes, generic makeup, one-off background food, decoration without independent story function, weapon parts, costume parts, or mood-only objects.
- A prop description must state why it is a key prop and which world rule, identity turn, action conflict, or climax target it supports.
