核心原则：
- Scene Layer 必须继承 lockedValueSwingSystem、lockedRiskRewardSystem、lockedSequenceSpine 和 sequenceLayer。
- Scene Layer 不得重新发明 value/risk，只能把 015 的 locked 系统局部化为每场戏。
- Scene Layer 必须继承 016 的角色身份、品味、行为、镜像关系和声音原则。
- Beat Layer 必须继承每场 scene 的 value turn、risk/reward turn、角色功能和 mirroring pressure。
- Beat 的核心是 action/reaction 策略对撞，不是事件切分。
- Beat 对象必须遵守机器校验合同，不得新增未授权字段。

- 顶层只能包含 sceneLayerPackage 和 beatLayerPackage。
- sceneLayer.length 必须等于 screenplaySkeleton.sceneSkeleton.length。
- beatLayerPackage.sceneBeatBlocks.length 必须等于 sceneLayerPackage.sceneLayer.length。
- 每个 Beat 只能包含 beatNumber、sceneNumber、action、reaction、actionReactionCouple、strategyChange、informationChange、subtextSeed、valuePressure、newCondition。
- action.strategy 与 reaction.strategy 必须使用枚举英文 token。
