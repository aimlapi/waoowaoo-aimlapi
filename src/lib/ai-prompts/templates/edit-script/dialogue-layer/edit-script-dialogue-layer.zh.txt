Dialogue Layer 职责边界：
- 这是 Screenplay 前的最后一个结构化对白层。
- 必须从 interactionLayerPackage.interactions 逐项推导关键对白，不得绕过 Dramatic Interaction Layer 另起冲突。
- 只处理适合说出口的关键 interaction；静默、动作或纯表演可省略。
- dialogue 字段是对白草稿，不是最终完整剧本文本，但必须已经具备可读台词、潜台词、人物声音、地域/方言质感和节奏。
- 不生成新场景、新 beat、新人物关系或新结局。
- 不输出 dialectProfile、characterVoiceEngine、localSpeechMarkers 或其他旧 Expression Layer 字段。
- 不输出 Story Development、Narrative Innovation、Expression Layer 相关字段或旧流程字段。

上游继承规则：
- 必须服从 Screenplay Skeleton Layer 的 centralDramaticQuestion、storyOriginDiagnosis、双层价值对立、regionalAesthetics 和 sceneSkeleton。
- 必须服从 015 Value-Sequence Loop 的 lockedValueSwingSystem、lockedRiskRewardSystem 和 lockedSequenceSpine；对白压力必须服务当前 sequence/scene 的 value swing 与 risk/reward。
- 必须服从 016 Character Identity & Voice Bible 的角色身份、品味、兴趣、性格、防御机制、行为习惯、说话特点和压力下声音变形。
- 必须服从 Sequence Layer 的 sequenceQuestion、turningPoint、riskRewardEscalation 和 crisisSequenceDesign。
- 必须服从 Scene Layer 的 sceneGoal、sceneAntagonist、informationFunction、setupPayoffUsage、regionalTextureRequirement 和 crisisSceneDesign。
- 必须服从 Beat Layer 的 action、reaction、actionReactionCouple、strategyChange、informationChange、subtextSeed、valuePressure 和 newCondition。
- 必须服从 Dramatic Interaction Layer 的 spokenSurface、hiddenLayer、subtextPlan、informationControl、dialogueTactics、behavioralExpression、microTurn 与 dialogueConstraint。
- 如果 informationControl.informationChange 是 none，禁止强行制造 reveal；只能维持策略压力、潜台词、权力变化和节奏变化。

对白生成原则：
- 每个 dialogueBeat 必须包含 speakerName、characterWant、tactic、subtext、dialogue、voiceExecution、surfaceTopic、realConflict、dramaticPurpose、naturalnessScore、conflictScore。
- 对白必须同时推进剧情、暴露人物、体现主题、制造冲突。
- 禁止纯信息对白。
- 禁止角色直接说出真实想法。
- 优先：角色谈论 A，实际争夺 B。
- 高级原则：说的 ≠ 想的；想的 ≠ 做的；观众知道的 ≠ 角色说出来的。
- dialogueTactics 必须继承 action/reaction 的策略对撞；tactic、surfaceTopic、realConflict 和 dramaticPurpose 都必须能追溯到 interactionLayerPackage.interactions。
- hiddenLayer.subtext 只能转化为潜台词、停顿、回避、误导、含混表达或生活化岔开话题，不能被角色直接说破。
- subtextPlan.mustNotSay 里的内容绝对不能原句进入 dialogue。

人物声音与地域/方言规则：
- voiceExecution 必须说明本段对白如何执行人物声音：句长、节奏、攻击性/回避性、文化身份、阶层感、情绪防御、口头习惯。
- 如果 Skeleton 或 Scene Layer 给出了具体地域、熟人社会、行业、家庭结构、方言或本地表达线索，dialogue 必须以可读密度体现地域/方言质感。
- 地域感不等于堆方言；可通过称呼、语气词、否定方式、时间说法、亲属关系、行业词、熟人社会话术和地方生活物件体现。
- 方言化必须服务人物与冲突，不得让对白难以理解。
- 如果上游没有明确地域特色，不要硬造具体方言，只做人物声音和生活口语节奏。
- 不允许所有角色共享同一种“克制、文艺、精准总结关系”的腔调。
- 尤其禁止配角说出过度概括主题的台词。

对白节奏规则：
- 对白必须满足 Natural Conversation + Dramatic Progression。
- 禁止 100% 剧情推进。
- 禁止 100% 生活闲聊。
- 目标比例：60-70% 角色目标与冲突，30-40% 生活化表达。
- dialogue 可以包含多句短对白，但必须围绕同一个 interaction 的策略对撞。
- dialogue 中可以有多名角色短句交锋；speakerName 写主要推动者，voiceExecution 必须说明每个说话者的声音差异。
- 短片优先短句、反问、打断、转移话题、沉默后的补刀，不要长篇解释。

错误方向：
女儿：你小时候从来不陪我。
父亲：对不起。
女儿：我恨你。

正确方向：
女儿：你记得我小学几年级转学吗？
父亲：当然记得。
女儿：那是哪一年？
（沉默）

质量要求：
- 只能输出上述 JSON Schema 中列出的字段，不得输出旧流程字段或额外字段。
- naturalnessScore 与 conflictScore 使用 0-10 数字。
- dialogueBeats 只能引用 Beat Layer 中真实存在的 beatNumber。
- sceneNumber 必须引用 Scene Layer 中真实存在的 sceneNumber。
- 不要把所有 beat 都写满对白；只处理关键 beat。
- 无对白 beat 可省略。
- 每个 dialogueBeat 必须能追溯到一个 Dramatic Interaction Layer sourceBeatNumber。
- 每段 dialogue 都必须体现 spokenSurface 表面话题、hiddenLayer 潜台词、dialogueTactics 策略对撞和 microTurn 微转折。
- 如果 informationChange=none，dramaticPurpose 不得写成 reveal、truth exposed、真相揭示或类似含义。
