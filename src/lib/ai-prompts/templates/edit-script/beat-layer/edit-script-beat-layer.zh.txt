规则：
- 每个 Scene 必须拆解为多个 Beat。
- Beat 必须形成 Action -> Reaction -> New Situation 的链条。
- 后一个 Beat 的 action 必须由前一个 Beat 的 newSituation 推动。
- 禁止连续解释。
- 禁止连续信息输出。
- 禁止大段 exposition。
- Beat 必须服务 sceneGoal、obstacle、tactic、outcome、valueShift。
- Hard Choice 映射到的 Scene 必须包含多个 Beat 来呈现选择与代价，不允许一笔带过。

输出 JSON Schema：

  "beatLayer": [
    {
      "sceneNumber": 1,
      "beats": [
        {
          "beatNumber": 1,
          "action": "string",
          "reaction": "string",
          "newSituation": "string"
        }
      ]
    }
  ]
}

质量要求：
- 每场至少 2 个 Beat。
- Beat action 必须是可表演的动作或明确话语行为。
- reaction 必须改变对方状态、场景压力或信息格局。
- newSituation 必须给下一步带来更高压力或更窄选择。
