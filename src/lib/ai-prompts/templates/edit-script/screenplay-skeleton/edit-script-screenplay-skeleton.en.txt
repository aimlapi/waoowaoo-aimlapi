Core rules:
- This layer only defines story-origin diagnosis, protagonist inference, conflict engine, three-act structure, value system, causality chain, and regional/spatial aesthetics.
- Do not output any scene list or quota-based scene-splitting field.
- The later Scene Layer will split scenes only by actual story location and time span; this layer must not pre-split one location by dramatic phase.
- storyOriginDiagnosis is the derivation root for value matrix, protagonist, inciting event, crisis moment, and location choices.
- The skeleton must fit the target duration. A short film may contain several dramatic phases, but the same location must not become multiple scene headings.

Field definitions:
- skeletonPremise: executable compressed premise without story prose.
- centralDramaticQuestion: the dramatic question the short must answer.
- storyCoreEngine:
  - incitingIncident: event, beforeState, afterState, actTurn.
  - globalGoal: objective, measurableTarget, physicalProofOfSuccess, deadlineOrConstraint.
  - dramaticProblem: problem, whyItCannotBeIgnored, howItLocksWithIncitingIncidentAndGoal.
  - protagonistWound: wound, woundOrigin, defensiveBelief, visibleBehavior.
  - gearLock: one sentence explaining how event, goal, wound, and obstacle lock together.
- storyOriginDiagnosis:
  - primaryOrigin / secondaryOrigin / rejectedOrigin: character, concept, or viewpoint; all different.
  - originReasoning, misdiagnosisRisk, derivationStrategy.
  - originDerivationChain with external/internal value oppositions, protagonist inference, disruptive event, contrast system, change mechanism, and structural implications.
- storyStructureBlueprint:
  - coreValueAndStoryTriangle.
  - valueConflictSystem.
  - storyFoundationAndEngine.
  - structuralBeats.
  - microSceneSpecification: state how later actual-location scenes must satisfy sceneGoal, sceneAntagonist, and sceneOutcome; do not generate a scene list.
  - causalityChain: exactly 10 causal sentences.
  - narrativeTexture.
  - regionalAesthetics.
