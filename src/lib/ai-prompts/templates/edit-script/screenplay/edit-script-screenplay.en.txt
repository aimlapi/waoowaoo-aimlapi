Hard boundaries:
- Do not write the screenplay directly from the premise.
- Execute the blueprint in this order: Screenplay Skeleton Layer -> Sequence Layer -> Scene Layer -> Beat Layer -> Dramatic Interaction Layer -> Dialogue Layer -> Screenplay.
- Screenplay Skeleton Layer provides skeletonPremise, centralDramaticQuestion, storyOriginDiagnosis, storyStructureBlueprint, and sceneSkeleton. It is the first structural commitment.
- Sequence Layer provides sequenceStrategy, actSequenceMap, sequences, crisisSequenceDesign, and sceneLayerContract. It turns the three-act skeleton into dramatic sequences.
- Scene Layer defines each scene's sceneGoal, sceneAntagonist, approach, outcome, externalValueTurn, internalValueTurn, turningPoint, crisisSceneDesign, and beatDesignContract.
- Beat Layer defines the action -> reaction -> strategyChange -> informationChange -> newCondition strategy-collision chain.
- Dramatic Interaction Layer defines spokenSurface, hiddenLayer, subtextPlan, informationControl, dialogueTactics, behavioralExpression, microTurn, and dialogueConstraint.
- Dialogue Layer defines key beats' speakerName, characterWant, tactic, subtext, dialogue, voiceExecution, surfaceTopic, realConflict, and dramaticPurpose, and it handles character voice, subtext, regional/dialect texture, and dialogue rhythm.
- Do not skip, merge, replace, or rewrite these intermediate layers.
- Only translate these layers into standard screenplay text.

Execution rules:
- First execute Screenplay Skeleton Layer story-origin diagnosis, scene count, dual value oppositions, crisisMoment, and three-act result. Do not add, delete, or replace skeleton scenes.
- Execute Sequence Layer sequenceQuestion, turningPoint, riskRewardEscalation, and crisisSequenceDesign. If the final story bypasses sequence progression and becomes a generic social issue, execution has failed.
- Every scene must express the Scene Layer external and internal value turns.
- Every scene must execute Scene Layer informationFunction, setupPayoffUsage, regionalTextureRequirement, and beatDesignContract: raising questions, planting clues, misdirecting, revealing partial truth, fully revealing, creating new questions, reversing expectations, or forcing harder choices.
- Every scene must contain a value change. If a scene has no value change, do not write it.
- The crisisSceneDesign scene must clearly show the external choice, internal choice, irreversible cost, and how it forces the ending.
- Every beat must express action -> reaction -> strategyChange -> informationChange -> newCondition. Do not write continuous explanation or continuous information output.
- Every key dialogue must execute Dramatic Interaction Layer spokenSurface, hiddenLayer, subtextPlan, informationControl, dialogueTactics, microTurn, and dialogueConstraint.
- If informationControl.informationChange is none, do not force a truth reveal in the screenplay.
- Concrete behavior, environment detail, and blocking are generated only here, but they must not overturn Scene Layer sceneAntagonist/approach, value turns, or Beat Layer action/reaction strategy collisions.
- Dialogue must follow Dialogue Layer and must not state subtext directly.
- Dialogue must execute Dialogue Layer character voice, dialect texture, and rhythm. If character names are removed, the audience should still roughly know who is speaking.
- Regional texture does not mean dialect stuffing. If upstream has a regional setting, weave address forms, particles, negation, time phrasing, kinship terms, industry terms, acquaintance-society talk, or local daily objects into key dialogue at readable density.
- Do not invent dialect or regional habits that conflict with upstream regional aesthetics.
- Keep dialect density readable. Do not turn every line into hard-to-read dialect.
- Do not let all characters share the same restrained, literary, relationship-summarizing language.
- Supporting characters especially must not speak over-generalized thematic lines.
- Dialogue must balance Natural Conversation + Dramatic Progression: roughly 60-70% character goal/conflict and 30-40% natural expression.
- Prefer dialogue where characters discuss A while actually fighting over B.
- No purely informational dialogue.
- Do not explain theme through lines.
- Write only story content here. Do not write camera language, shot sizes, composition, camera movement, editing rhythm, group/single, video-generation prompts, sound effects, BGM, or postproduction notes.
- This screenplay will feed downstream character, location, prop, style-reference, and storyboard generation.
- Downstream assets and storyboards treat this screenplay as the single source of story truth, so characters, locations, causal events, action progression, and ending state must be clear.

Writing requirements:
- Fit the target duration. Do not write a feature-length story.
- Scene count follows Scene Layer.
- Character count follows Skeleton, Scene, Beat, Interaction, and Dialogue Layer. Do not introduce unrelated characters.
- Use one stable scene heading format: "Scene N | INT/EXT. Location - Time". N starts at 1 and increases continuously.
- Every new scene must start with a scene heading, then action or dialogue.
- Action paragraphs must contain visible, performable story facts that downstream assets, style references, and storyboards can parse. Avoid psychological explanation, theme summary, or director commentary.
- Dialogue paragraphs contain only spoken lines. If tone, pause, or performance is needed, put it in parentheses after the character name, such as "Kyle (low):".
- You may write "Narrator (V.O.)" or "Character Name (O.S.)", but the line must be story-needed audio, not subtitles or on-screen text.
- A character's first appearance must match the Character List's stable identity and visual traits. Do not change appearance, clothing, or identity ad hoc in action paragraphs.
- Actions must be concrete and visible. Avoid abstract concepts, inner-monologue exposition, or directorial explanation.
- The ending must match Screenplay Blueprint resolution, valueQuadrant, and sceneOutcome. Do not become suddenly happy, suddenly preachy, or explain theme through dialogue.
- Do not use production terms such as "camera", "close-up", "push in", "cut", "CUT TO", "transition", "sound effect", "music", "BGM", "subtitle", or "text overlay".
