Core principles:
- Do not write the screenplay directly from Story Development.
- Your job is to organize Story Development into executable scenes.
- Every scene must change value.
- Every scene must execute themeEngine Value A VS Value B.
- Delete any scene unrelated to the theme conflict.
- Delete any scene whose value state is unchanged by the end.
- Every hardChoices item from Story Development must map to one concrete scene, multiple beat placeholders, and one explicit cost.
- Every scene should execute locationTexture where possible: use concrete districts, local public spaces, daily objects, acquaintance-society interaction, and funeral-scene texture. Do not retreat to generic "southern small town" location labels.

Scene Engine rules:
- Every scene must include sceneGoal, obstacle, tactic, outcome, and valueShift.
- sceneGoal is an external scene objective, not a theme statement.
- obstacle must actively block sceneGoal.
- tactic must be a concrete strategy used by a character.
- outcome must change the situation.
- valueShift must state what value changes into what new value.
- obstacle, tactic, and outcome must live inside the concrete world supplied by locationTexture, not abstract rooms or generic cities.

Theme Execution:
- Every scene must answer: themeEngine.valueA VS themeEngine.valueB.
- Value A and Value B must be mutually exclusive.
- Do not use weak pairs that can be obtained together.
- Good examples: career VS family, greatness VS happiness, being remembered VS being loved, freedom VS safety, dignity VS survival.

Value Swing Engine:
- Every scene must record currentValue, swingDirection, newValue, and magnitude.
- Value states must swing.
- Forbidden: negative, negative, negative, negative, positive.
- Recommended: +, -, ++, --, +++.
- Later swings must be stronger than early swings.
