# 导演与剪辑时间线核心

## 作用

从完整作品出发，把故事事实组织为能被独立生成、随后真实剪辑的连续镜头。`outputKind=video_prompt_set` 时必须同轮读取 `director-core`、`video-direction` 与 `quality-review`；三份 Skill 服务同一个 strict 结果。

## 成片优先

先判断作品整体的开场钩子、因果推进、转折、情绪峰值和结尾落点，再设计镜头。镜头不是按模型时长机械切块，也不是前一段生成后临时续写下一段。

每个镜头只承担一个独特的剪辑职责和一个可见动作节拍：

- 建立地点或关系；
- 提供原因；
- 展示动作；
- 展示结果；
- 揭示信息；
- 承载反应；
- 完成收束。

同一个动作节拍不得换景别、换角度或加特写再演一次。相邻镜头沿同一时间轴向前，后一镜第一帧必须继承前一镜已经发生的结果。

## 一个生成段就是一个镜头

一个 `video_prompt_set.segment` 是一个连续摄影镜头和一次 provider 生成。段内禁止切镜、快切、蒙太奇或多机位。需要多个 cut 时拆成多个 segment，再由真实剪辑组合。

独立生成无法可靠进行帧级半动作接力，因此每段结束在已完成、可观察的动作落点上。下一段从新的动作节拍开始。

## 场面调度

- 人物位置用稳定场景锚点、画面区域、前中后景、身体朝向与道具关系共同表达。
- 人物移动写出起点、路径和落点；落点成为下一镜入口事实。
- 有人物的镜头必须有世内视线目标。除明确的口播、vlog 或打破第四面墙外，不看镜头。
- 空镜和特写必须承担信息、悬念、反应、尺度或切点职责，不能只为填时长。

## 摄影机

先确定镜头目的和动作，再选择景别、机位、主体落位与一种主要运镜。相邻镜头至少改变景别、机位角度、主体落位中的两项，避免连续相同构图，但视觉变化不能制造时间回退。

居中构图只在仪式、对称、审讯、正面陈述等明确动机下使用。资产参考图的白底、拼版、正面站姿和居中直视不是剧情镜头设计。

## 剪辑接缝

每个非首镜头拥有一个明确的进入关系：

- 位置关系：主体或关键物从前一出口位置进入新构图；
- 银幕方向：运动和朝向保持可读；
- 视线关系：前一镜建立注视，后一镜揭示对象；
- 动作结果：前一镜完成动作，后一镜展示其新后果；
- 道具状态：持有、开启、破损、位移等变化被继承；
- 图形关系：形状、光、色或运动结果形成 match；
- 声音关系：同期声延续或新声先行并有来源。

禁止用叠化、淡入淡出或透明重叠掩盖接缝。声音桥有动机才使用。

## 声音

视频镜头默认是完整音画单位。设计逐字对白、动作同步声、空间环境声、必要静默边界与声音桥。无对白镜头仍应有符合画面的可听环境或动作声，除非剧情明确要求可验证的完全静默。

角色音色引用只定义声音身份，不得把试听内容当对白。音乐与镜头原生对白/环境/拟音分开规划。

## 时长

时长来自对白语速、动作完成、反应和必要停顿。`fixed` 严格满足用户总时长；`derive` 只取内容真正需要的时长。每段只用 production context 允许的时长，不向最大值凑数，不用重复动作或空停顿填满。

## 自检

- 是否完整看待整部作品并形成清楚剪辑弧？
- 是否每段一个镜头、一个动作节拍、一个完成落点？
- 是否不存在段内切镜、快切或蒙太奇？
- 相邻 entry/exit 是否是同一可观察状态，后镜是否真正推进？
- 景别、机位与主体落位是否至少改变两项且仍保持轴线可读？
- 对白、环境和同步声是否完整，角色声音身份是否正确？

## 边界

本 Skill 提供导演、场面调度与剪辑关系方法。最终 Prompt 编译、媒体编号、能力限制、任务状态和持久化由服务端负责。
